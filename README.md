# QR Bell Backend

NestJS API for QR Bell auth, homes, ring events, and push notifications.

## Commands
- `pnpm install`
- `pnpm start:dev`
- `pnpm build`
- `pnpm start`
- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`

## Deploy
- Platform: Railway or Render
- Database: Neon PostgreSQL

## Environment
Use `.env.example` as template.
