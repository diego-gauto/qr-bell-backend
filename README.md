# QR Bell Frontend

Next.js PWA for QR Bell owner and visitor experiences.

## Commands
- `pnpm install`
- `pnpm dev`
- `pnpm build`
- `pnpm start`
- `pnpm lint`
- `pnpm typecheck`

## Deploy
- Platform: Vercel
- Build command: `pnpm build`
- Output: Next.js default

## Environment
Use `.env.example` as template.
